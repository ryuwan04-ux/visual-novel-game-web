# 🎮 Visual Novel Game Web Platform

전기·전자 과학동아리를 배경으로 한 AI 기반 비주얼 노벨 게임 웹앱입니다.

## 🎯 프로젝트 개요

- **장르**: 교육 × 연애 비주얼 노벨 (Visual Novel)
- **배경**: 고등학교 전기·전자 과학동아리
- **기술**: React + TypeScript + Ink Script + OpenAI API
- **특징**: AI가 프롬프트를 받아 자동으로 게임 시나리오 생성

## 📖 스토리 개요

### 설정
- **주인공**: 동아리 부장 (전기·전자 전문가)
- **갈등**: 부원 부족으로 폐부 위기
- **전개**: 초보 부원 4명이 입부 → 주인공이 가르침 → 연애 진척 → 함께 프로젝트 완성

### 히로인 4명

| 이름 | 입부 동기 | 성격 | 배우는 분야 | 갭모에 |
|------|---------|------|-----------|-------|
| **유나** | "부장님이 좋아서" (진짜 이유) | 밝고 적극적 | 기초 회로/납땜 | 강한 척하지만 실은 부장을 많이 의존 |
| **지은** | "학점 때문" | 진지하고 논리적 | C언어/아두이노 프로그래밍 | 완벽주의자인데 실수하면 쩔쩔매함 |
| **하연** | "친구 따라" | 소심하고 예민 | 전자기학 이론 | 자신감 없지만 일단 이해하면 깊이 있는 통찰 |
| **민지** | "재미있을 것 같아" | 장난기 많고 호기심 많음 | 센서/부품 활용 | 태평스럽지만 위급한 상황에서 집중력 발휘 |

## 🚀 시작하기

## 🎮 게임 흐름

1. **프롬프트 입력 단계**
   - 사용자가 게임 상황/캐릭터/감정 설정 입력
   - 예: "유나에게 납땜 기초를 가르치는 상황, 유나가 실수함"

2. **AI 시나리오 생성**
   - OpenAI API로 프롬프트 처리
   - Ink 스크립트 형식으로 반환

3. **게임 실행**
   - Ink 런타임이 스크립트 파싱
   - 비주얼 노벨 플레이어에서 렌더링
   - 사용자 선택에 따라 분기

4. **상태 관리**
   - 호감도, 이해도, 선택 기록 저장
   - 엔딩 조건 체크

## 📊 호감도/이해도 시스템

각 히로인마다:
- **호감도** (0~100): 선택에 따라 증감
- **이해도** (0~100): 학습 내용 이해 정도
- **신뢰도** (0~100): 부장님에 대한 신뢰

### 엔딩 조건
- **True Ending**: 호감도 80+ & 이해도 90+ & 프로젝트 완성
- **Good Ending**: 호감도 60+ & 이해도 70+ & 프로젝트 완성
- **Normal Ending**: 프로젝트 완성
- **Bad Ending**: 폐부 (선택 실패)

```

[캐릭터 정보]
이름: {character_name}
성격: {personality}
배우는 분야: {learning_field}
현재 이해도: {understanding}%
현재 호감도: {affection}%

[상황]
{situation_description}

[요청]
- Ink 스크립트 형식으로 작성
- 주인공의 선택지 3개 포함
- 선택에 따른 히로인 반응 다름
- 게임 감정 포인트 [emotion_point] 포함
- 이해도와 호감도 변화 수치 명시 (예: +호감도 15, +이해도 20)

출력 형식:
```

[대사]
{dialogue}

[배경]
{background}

[히로인 표정]
{expression}

선택지:
* [선택 1]
  + 호감도: {+/-number}
  + 이해도: {+/-number}
* [선택 2]
  + 호감도: {+/-number}
  + 이해도: {+/-number}
* [선택 3]
  + 호감도: {+/-number}
  + 이해도: {+/-number}
```
```
