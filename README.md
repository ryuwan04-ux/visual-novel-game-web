# 비주얼 노벨: 전기·전자 동아리

고등학교 전기·전자 과학동아리를 배경으로 한 감정 육성 게임입니다.

## 🎮 게임 개요

**장르**: 비주얼 노벨 / 감정 육성 게임
**플랫폼**: Web (React + TypeScript)
**언어**: 한국어

## 📖 스토리

동아리 부장 **류완**은 폐부 위기에 처한 동아리를 살리기 위해 새로운 부원 4명을 모집했습니다.
- 🌟 **성원** - 밝고 적극적 (회로/납땜)
- ❄️ **세준** - 츤데레 성향 (프로그래밍)
- 😢 **예준** - 소심하고 예민 (전자기학)
- 🎮 **동진** - 장난기 많고 호기심 많음 (센서)

각 부원과의 관계를 발전시키며 **스마트 하우스 프로젝트**를 완성하는 것이 목표입니다.

## 🎯 게임 시스템

### 스탯 시스템
- **호감도** ❤️: 캐릭터와의 친밀감
- **이해도** 💡: 기술적 숙련도
- **신뢰도** 🤝: 캐릭터를 얼마나 신뢰하는가
- **우정도** 👋: 캐릭터들과의 관계

### 학습 시스템
1. **기초 회로/납땜** (성원)
2. **C언어/아두이노** (세준)
3. **전자기학 이론** (예준)
4. **센서/부품 활용** (동진)

### 미니게임
- ⏱️ **납땜 타이밍 맞추기** (10초)
- 🔍 **잘못 꽂힌 부품 찾기** (15초)
- 🐛 **코드 디버깅** (20초)

### 대치 씬
학교 귀가길 일진 무리를 마주치는 상황

## 🎬 엔딩 조건

| 엔딩 유형 | 조건 | 설명 |
|---------|------|------|
| **트루 엔딩** | 호감도 80+, 이해도 90+, 신뢰도 75+, 프로젝트 완성 | 모든 캐릭터와 깊은 신뢰를 구축 |
| **굿 엔딩** | 호감도 60+, 이해도 70+, 신뢰도 60+, 프로젝트 완성 | 충분한 관계 발전과 프로젝트 완성 |
| **노멀 엔딩** | 프로젝트 완성 | 최소한의 조건만 충족 |
| **배드 엔딩** | 프로젝트 미완성 | 동아리 폐부 또는 대치 씬 실패 |

## 🛠 기술 스택

### Frontend
- **React 18** - UI 라이브러리
- **TypeScript** - 타입 안정성
- **Zustand** - 상태 관리
- **CSS3** - 스타일링 & 애니메이션

### Build & Deploy
- **Vite** - 빌드 툴
- **GitHub Pages** - 호스팅
- **Node.js** - 런타임

## 📁 프로젝트 구조

```
src/
├── components/           # React 컴포넌트
│   ├── GameContainer/    # 메인 게임 컨테이너
│   ├── SceneRenderer/    # 씬 렌더링
│   ├── BackgroundDisplay/# 배경 표시
│   ├── ChoiceButtons/    # 선택지 버튼
│   ├── MiniGameContainer/# 미니게임
│   └── CharacterDisplay/ # 캐릭터 표시
│
├── types/                # TypeScript 타입 정의
│   ├── game.ts           # 게임 기본 타입
│   ├── scene.ts          # 씬 타입
│   └── confrontation.ts   # 대치 씬 타입
│
├── store/                # 상태 관리 (Zustand)
│   └── gameStore.ts      # 게임 상태 스토어
│
├── utils/                # 유틸리티 함수
│   ├── gameEngine.ts     # 게임 엔진
│   ├── saveManager.ts    # 저장/로드 시스템
│   ├── audioManager.ts   # 오디오 관리
│   ├── endingManager.ts  # 엔딩 시스템
│   └── confrontationEngine.ts # 대치 씬 엔진
│
├── data/                 # 게임 데이터
│   ├── gameData.ts       # 캐릭터, 배경, 모듈 데이터
│   └── sceneData.ts      # 씬 데이터
│
└── App.tsx              # 메인 앱 컴포넌트
```

## 🚀 실행 방법

### 설치
```bash
# 저장소 클론
git clone https://github.com/ryuwan04-ux/visual-novel-game-web.git
cd visual-novel-game-web

# 의존성 설치
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

브라우저에서 `http://localhost:5173` 접속

### 빌드
```bash
npm run build
```

### 배포
```bash
npm run deploy
```

## 🎨 UI/UX 특징

- **다크 테마**: 눈이 편한 자주색과 파란색 톤
- **부드러운 애니메이션**: 모든 전환에 페이드/슬라이드 효과
- **반응형 디자인**: 모바일/태블릿/PC 모두 지원
- **명확한 피드백**: 선택 시 스탯 변화 즉시 표시
- **글래스모피즘**: 모던한 반투명 UI 요소

## 💾 저장 시스템

- **자동 저장**: 30초마다 자동 저장
- **슬롯 저장**: 최대 5개 슬롯에 수동 저장 가능
- **로컬스토리지**: 브라우저 로컬스토리지에 저장
- **저장 정보**: 진행 상황, 스탯, 완료한 씬, 플레이 시간
